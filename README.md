# LifeLeft / 인생잔량

시간·돈·횟수의 잔량 계산 서비스.

- 제품 기준: `docs/MVP_SPEC.md`
- 인프라 기준: `docs/INFRASTRUCTURE.md`
- 기술: Next.js + TypeScript + Recharts
- 배포 형태: Static Export
- 저장: 브라우저 우선
- DB: 없음
- 신규 서버: 없음

## 현재 계산기

- 출근 잔량
- 월급 잔량
- 주말 잔량
- 회사 누적시간
- 구독 누적
- 생존 잔량

## 로컬 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run typecheck
npm run build
```
