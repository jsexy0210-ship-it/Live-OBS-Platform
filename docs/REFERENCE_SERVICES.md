# 벤치마킹 사이트 전체 목록

> 결정일: 2026-10-07 (KST)
> 대표님 지시: 「벤치마킹할 사이트 다 기록하고 다 해외사이트인가?」
> 방향: Streamlabs를 주요 기준으로 최대한 벤치마킹하며, 웹을 먼저 진행한 뒤 OBS 플러그인으로 확장한다.

## 국내·해외 구분

모두 해외 서비스는 아니다. PRISM Live Studio, 투네이션, TWIP, Sauce Flex, Grip Cloud, 아임웹, 카페24는 국내 서비스 비교 대상이다. Shoplive는 한국에서 출발해 글로벌 시장에 서비스하는 비교 대상이다. 아래 구분은 제품의 출발·서비스 배경 기준이며 현행 계약 법인·본사·소유주의 국적을 모두 검증했다는 뜻은 아니다. 한국어 페이지 유무로 국내외를 구분하지 않는다.

## 적용 순서

1. 웹 설계: Streamlabs의 전체 경험, StreamElements의 오버레이 설정, StreamYard의 쉬운 조작을 비교한다.
2. 판매 운영: SoldLive·CommentSold와 주문/상품/재고 흐름을 비교하고 국내 쇼핑몰·라이브커머스 후보를 함께 확인한다.
3. 국내 사용성: 국내 방송·후원 플랫폼 연결과 원화·한국어·국내 판매 업무 지원 범위를 비교한다.
4. 웹 진행 후 OBS 플러그인: 기존 웹 기능을 OBS 내부에서 사용하는 방식과 간편 연결을 검토한다.

## 조사 상태와 인수인계

- 이 문서는 대화에서 언급한 벤치마킹·가격 비교 후보 16개를 보존한 목록이다. 전 서비스의 상세 분석 완료를 뜻하지 않는다.
- Streamlabs 주요 공개 페이지, SoldLive·CommentSold·Shopify·아임웹·카페24의 가격 관련 페이지는 앞선 조사에서 확인했다. 가격은 적용 시점에 다시 확인한다.
- PRISM은 NAVER 공식 저장소 https://github.com/naver/prism-live-studio 에서 제품 존재를 확인했다. 현행 플랜·기능 한도는 미확인이다.
- StreamElements·Restream·StreamYard·Lightstream은 추가 상세 조사 대상이다.
- 국내 방송·후원·라이브커머스 홈페이지는 앞선 조사에서 환경 네트워크 제한이 있었다. TWIP의 현행 운영 여부, Grip Cloud의 현행 공식 도메인 등은 확인이 남아 있다. 접속 차단은 서비스 종료 근거가 아니다.
- 다음 작업은 비교 대상 페이지, 관찰 사실, 우리 화면/기능에 적용할 점을 기록하고 디자인 정본과 구현을 함께 갱신한다.
