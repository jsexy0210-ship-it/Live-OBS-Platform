# 정보구조(IA) — 전체 화면

> 작성일: 2026-10-02 (KST) · 상태: 초안 (디자인 결과로 보완 후 확정)
> 화면 ID 규칙: `영역-번호`. 영역 코드 — PF 플랫폼 소개·가입, AU 공통 인증, MA 마스터 관리자, SA 판매자 관리자, OV OBS 오버레이, SH 구매자 쇼핑몰
> 권한 계층: 마스터 관리자 > 판매자 > 구매자·시청자 (`CLAUDE.md` 제품 원칙)

## 최상위 구조

```text
Live OBS Platform
├─ PF 플랫폼 소개·가입 (공개)
├─ AU 공통 인증 (마스터·판매자·구매자 각각 분리된 로그인)
├─ MA 마스터 관리자 콘솔 (최고관리자/운영/CS/조회 전용)
├─ SA 판매자 관리자 (판매자·판매자 직원)
├─ OV OBS 오버레이 (판매자별 비공개 토큰 URL)
└─ SH 구매자 쇼핑몰 (판매자별 쇼핑몰)
```

  └─ SA-026 입금 확인 (무통장 대기·단건/일괄 확인·입금 기한·자동 취소·기한 전 알림)

  ├─ SA-032 지급·회수 원장 (대기 / 성공 / 실패)
  ├─ SA-033 회원별 잔액

  ├─ SA-041 회원 목록·검색
  ├─ SA-042 회원 상세 (주문·적립금·등급·회원 메모·구매 제한)

  └─ SA-062 법정 고지·약관 (미성년자 구매 정책, 청약철회 고지 미리보기, 약관·처리방침 버전·재동의, 구매안전서비스 가입 정보, 사업자 정보 표시)
SA-070 결제(PG) 연결 (판매자 명의 PG 상태·연결·해제)

SA-090 구독·결제 (내 요금제, 결제 수단, 청구 내역, 해지)
SA-100 직원 계정·권한 (대표자가 직원 계정을 직접 만들고 권한을 항목별로 켜고 끔. 고정 역할 없음)
SA-110 공지사항 · 문의하기 (플랫폼에 문의)

## SH 구매자 쇼핑몰 (판매자별)

> 모든 SH 화면은 모바일(390)과 PC(1440) 두 가지로 만든다. PC 보드 ID는 `SH-xxx-PC` (2026-10-02 대표님 지시).

```text
SH-001 쇼핑몰 홈
SH-002 상품 목록·검색·필터
SH-003 상품 상세 (상품 문의 목록·문의하기, 비공개 선택)
SH-004 장바구니
SH-005 주문서 (방송 닉네임 입력, 적립금 사용, 현금영수증·세금계산서 신청)
SH-006 결제 진행 → SH-007 주문 완료 / SH-008 결제 실패
SH-009 미성년자 주문 제한 안내 (판매자가 「미성년자 구매 막기」를 켠 경우)
SH-010 로그인 · SH-011 회원가입 · SH-012 비밀번호 찾기
SH-020 마이페이지
  ├─ SH-021 주문 내역 → SH-022 주문 상세 (취소 요청, 현금영수증·세금계산서 발행 확인)
  ├─ SH-023 내 적립금
  ├─ SH-024 회원정보 수정
  ├─ SH-025 알림 설정
  └─ SH-026 내 문의 (상품 문의·1:1 문의 작성, 답변 확인)
SH-030 쇼핑몰 공지 · 이용안내
SH-040 쇼핑몰 정지·준비 중 안내
```

## EM 구매자 주문 메일 (판매자별 브랜드, 폭 600px)

EM-001 주문 완료 (주문대기 순서 안내, 무통장이면 입금 계좌·기한)
EM-002 발송 (택배사·송장번호, 배송 조회 버튼)
EM-003 배송 완료 (적립금 안내, 방송 다시보기)
EM-004 취소·환불 (취소 사유, 환불 금액·수단·예정일, 부분 취소)
- 받는 분 이름·연락처·주소는 가리지 않는다. 거래 메일이라 수신 거부 안내는 없다. 판매자가 SA-080에서 종류별로 켜고 끈다.
