# 쇼핑몰 설정 기본값

대표님 지시 「파트너스 쇼핑몰 가입 시 디폴트 값 지정」(2026-10-06)의 정본 표입니다. 코드·스키마에 이미 있는 값은 반복하지 않고 **무엇을 언제 채우는지·근거·비워 두는 것**만 둡니다.

## 채우는 시점

- 새 쇼핑몰: 가입 신청으로 쇼핑몰이 만들어질 때 같은 트랜잭션에서(`lib/server/sellers/application.ts` → `lib/server/sellers/shopDefaults.ts`). 이미 행이 있으면 건드리지 않습니다.
- 기존 쇼핑몰: 마이그레이션 `20261006270000_shop_defaults`가 **행이 없는 곳에만** 채웁니다. 이미 입력한 값은 덮어쓰지 않고, 다시 돌려도 같습니다.
- 값은 칼럼 기본값(`prisma/schema.prisma`)이며 읽는 쪽 코드의 폴백과 같습니다. 그래서 화면·동작은 그대로이고 DB에 행이 있다는 점만 다릅니다.

## 채우는 것

| 설정 | 모델 | 기본값 | 근거 |
|---|---|---|---|
| 배송 정책 | SellerShippingPolicy | 무료배송 꺼짐, 기본 배송비 3,000원, 도서산간 +3,000원(제주·울릉 우편번호 범위), 받는 방법 즉시, 발송 기한 3일, 반품 배송비 3,000원·교환 배송비 6,000원, 무료배송 기준 금액 없음 | PRODUCT_SCOPE 43행(배송비 3,000·도서산간 +3,000). 반품·교환 배송비와 발송 기한은 코드 폴백(`orders/shipping.ts DEFAULT_SHIPPING_POLICY`)과 같은 값이며 문서 근거는 없음 → 대표님 확인 대기 |
| 주문 정책 | SellerOrderPolicy | 미입금 자동 취소 켜짐·24시간, 취소 시 재고 복구 켜짐, 자동 배송완료 켜짐·7일, 자동 구매확정 켜짐·7일, 입금 기한 알림 켜짐, 미입금 구매 제한 켜짐(켠 시각 없음), 결제 후 취소 제한 꺼짐, 배송 자동 조회 꺼짐 | PRODUCT_SCOPE 38~46행, 배송 자동 조회 꺼짐은 COST_POLICY. **켠 시각(`*EnabledAt`)은 만들지 않고 기존 로직(`orders/overdue.ts`)이 정합니다.** `savedAt`이 없으면 파트너스가 아직 저장하지 않은 기본 행입니다(온보딩 「주문 정책」 완료 판정) |
| 재가입 제한 | SellerMemberPolicy | 꺼짐, 30일 | PRODUCT_SCOPE 52행, ARCHITECTURE 153행(기능 자체는 `available=false`) |
| 주문 알림 | SellerOrderNotificationPolicy | 주문 완료·발송·배송 완료·취소/환불 4종 켜짐 | 코드·스키마 주석(SA-080). 문서 직접 근거는 없음 |
| 리뷰 정책 | ProductReviewPolicy | 바로 게시, 적립금 0원(글·사진), 작성 기간 30일, 금지어 없음 | 코드 폴백과 같은 값. 문서 근거 없음 → 적립금·기간은 대표님 값 대기 |
| 검색 노출 | ShopSeo | 검색 노출 켜짐, 사이트맵 켜짐, 검색 제목·설명·템플릿·인증 코드 없음(쇼핑몰 이름 등으로 대체) | PRODUCT_SCOPE 17행(공유 제목·설명이 없으면 쇼핑몰 이름·로고) |
| 진열 설정·영역 | ShopDisplaySetting, ShopDisplaySection | 정렬 신상품순, 품절 뒤로·품절 숨김·방송 상품 먼저 꺼짐. 영역 2개: 추천 상품·신상품(보임, 8개) | 코드 폴백(`shop-display/service.ts DEFAULT_SECTIONS`). 이미 진열 설정을 저장한 쇼핑몰은 영역을 건드리지 않음 |
| 회원 등급 정책 | MemberGradePolicy | 자동 재산정 꺼짐, 기간 6개월, 매월, 한 단계씩 강등 | ARCHITECTURE 247행(자동 재산정 기본 꺼짐). 기간 6개월·매월은 코드 기본 |
| 유튜브 | YoutubeSellerSetting | 채팅 가져오기 기본 꺼짐 | 코드 폴백 |

## 만들지 않는 것 (이유)

| 설정 | 이유 |
|---|---|
| 적립금 정책(RewardPolicy) | 행이 없으면 「정책 없음」으로 보이고 등급별 적립률은 근거 값이 없음. 행을 만들면 「설정됨」으로 보임 → 적립률을 대표님이 정하면 넣음 |
| 오버레이 레이아웃(OverlayLayout) | 저장한 적 없으면 기본 템플릿(`queue_focus`, ARCHITECTURE 306행)을 읽는 쪽이 대신 줌. 행이 있으면 온보딩이 완료로 판정함 |
| 로고·파비콘·브랜드 색 | 파트너스가 올려야 함. 없으면 첫 글자·로고에서 자동 생성·플랫폼 기본 색(PRODUCT_SCOPE 17행) |

## 근거가 없어 비워 두는 것 (대표님 값·확인 필요)

- 등급별 승급 기준 금액(`MemberGrade.minAmount`, 지금 전부 0원. 자동 재산정이 꺼져 있고 켜려면 기준 금액이 순서대로 커야 해서 0원 그대로는 승급이 일어나지 않음)
- 등급별 카드·무통장 적립률, 등급 배송 혜택, 랭킹 보너스 금액, 적립금 사용 조건
- 반품·교환 배송비·무료배송 기준 금액·발송 기한(코드 폴백 값을 채웠으나 문서 근거 없음), 리뷰 적립금·작성 기간
- 이용약관·개인정보처리방침(기본 서식은 게시 조건이 있어 자동 게시 금지, ARCHITECTURE 329행), 사업장 주소·고객센터·에스크로·미성년자 고지, 이용안내·교환·환불 글, 한 줄 소개·상단 공지
- 무통장 계좌, 현금영수증 발행자, SEO 인증 코드, 기본 카테고리·공지·FAQ
- 메시지 충전·충전금·발송 단가(MA-086 플랫폼 정책)
