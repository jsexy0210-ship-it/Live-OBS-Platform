# 스트림샵 랜딩 PF-001

기준일: 2026-10-07 KST. 대표님 지시: 「랜딩 화면도 Streamlabs를 벤치마킹해서 거의 비슷하게 만들되, 우리 스타일로 적용한다」.

2026-10-09 KST 대표님 「메인으로 올려」 지시에 따라 두 전략 브랜치의 승인 기록과 PF-001을 최신 main 기준으로 통합한다. 운영 주소·DB 브랜딩·OAuth·비밀 설정은 범위에 포함하지 않는다.

## 적용

- 경로: `/about`. 기존 `/` 로그인 경로와 가입/로그인/요금/기능 경로 유지.
- 참조: https://streamlabs.com/ultra · https://streamlabs.com/ko-kr/ultra · https://streamlabs.com/plugin-for-obs . 앞선 공개 페이지 조사에서 확인한 가치 제안→기능→제품 사용 장면→플랜 비교→FAQ→가입 흐름을 적용한다.
- 브랜드: 스트림샵 / StreamShop, 승인한 S·재생 버튼 심볼을 배경 제거해 사용. 인디고 #4F46E5, 민트 #80E8C1, 잉크 #171A24, 클라우드 #F7F8FC. 심볼 파일은 `public/branding/streamshop-symbol.png`이며 Next Image로 제공한다.
- 2026-10-10 대표님 최신 승인: 워드마크 끝 점·본문 문장 마침표·장식 텍스트 화살표와 별을 제거한다. URL·숫자·기능 SVG 및 FAQ 펼침 표시는 유지한다. 기존 방송 사진 슬롯은 가상 한국인 성인 진행자의 라이브커머스 실사로 교체하며 정본과 구현을 동기화한다.
- 사진: `public/landing/live-host-landscape-20261010.webp`(1536×1024, hero·가로 방송 재사용), `live-host-portrait-20261010.webp`(941×1672, 세로 방송). 내장 이미지 생성 도구로 각 1회 생성하고 글자·로고·UI가 없는 원산출물을 보존한 채 WebP 품질 88로 형식만 변환했다. 프롬프트: 실존 인물을 모방하지 않는 가상 한국인 성인 진행자, 자연광의 실제 라이브커머스 촬영 장면, 가로는 머그 시연·세로는 토트 시연, 얼굴과 손·제품이 크롭 안에 들어오며 사진 내 글자·로고·통계·UI 없음.
- 기존 방송 프로그램을 사용하는 판매자를 위해 내 쇼핑몰·오버레이·주문대기·방송 이후 운영을 소개한다. Streamlabs 문구·테마·제품 화면을 복사하지 않는다.
- 방송 화면·주문 카드·상품 그래픽은 샘플 예시로 명시했다. 고객 사용량이나 실적 수치는 넣지 않았다.
- 서버 `getPublicPlan`의 가격·플랜 이름·체험 일수만 표시한다. API/DB 실패·가입 가능 플랜 없음은 별도 안내한다. 플랜별 체험 CTA를 구분하고, 결제대행/발송 등 별도 비용을 안내한다.
- 마케팅 페이지의 장식용 예시에 조작 가능한 것처럼 보이는 가짜 버튼을 두지 않는다. 가입·로그인·기능·요금·공지·약관 링크는 기존 경로를 사용한다. FAQ는 native details/summary다.
- 모바일에서도 요금과 FAQ를 제공한다. 키보드 포커스·본문 바로가기·reduced-motion 규칙을 포함한다.
- 2026-10-10 대표님 후속 승인: 공개 세부 페이지(`/features`, `/pricing`, `/faq`, `/notices`, `/notices/[noticeId]`, `/terms`, `/privacy`)와 가입 신청 공통 머리·꼬리에 같은 승인 심볼·점 없는 워드마크·공개 메뉴/CTA 톤을 사용한다. 표시 서비스명은 스트림샵으로 정합하고 기존 경로·본문 기능·가격 정책·법적 문서·공지 저장 내용은 유지한다. 공개 메타데이터는 소개 브랜딩을 승계하며 각 페이지 제목·설명을 유지한다. 가입 신청의 파비콘만 파트너스 대상 브랜딩을 우선한다.
- 기본 파비콘·홈 화면 아이콘 색상은 소개 보라 원본, 마스터 틸 `#0F766E`, 파트너스 오렌지 `#EA580C`로 구분한다. 기존 업로드가 우선하며 자동 OG 카드 템플릿·버전과 관리자/파트너스 전체 테마는 유지한다.
