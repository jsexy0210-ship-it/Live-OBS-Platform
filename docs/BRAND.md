# 서비스명: 스트림샵 (StreamShop)

> 확정일: 2026-10-07 (KST)
> 최신 대표님 지시: 「스트림샵으로 확정한다」

## 명칭 변경 이력 (2026-10-07)

- 대표님이 https://www.shopcast.kr/ 를 제시하며 같은 이름의 사이트가 있다고 알렸다.
- 명칭 선택은 있었으나 동명 서비스·상표 확인 전에 확정으로 기록하고 시안을 만든 순서가 성급했다. 브랜드 선택 이력과 실제 사용 가능 여부를 구분한다.
- 이번 직접 접속은 환경 프록시의 CONNECT 403으로 차단됐다. 사이트의 업종·운영 주체·상표 권리 상태는 확인하지 못했다. 확인한 사실처럼 추정해서 기록하지 않는다.
- 이후 대표님이 **스트림샵**으로 최종 선택했다. 샵캐스트 관련 재검토와 이전 명칭 확정 문구는 과거 기록이며 현재 서비스명은 스트림샵이다.
- 새 후보를 제안할 때는 동명 서비스·관련 업종·주요 도메인을 먼저 조사하고 상표 검색 결과와 미확인 항목을 함께 제시한다.

## 확정 표기

- 한글 서비스명: **스트림샵**
- 영문 표기: **StreamShop**
- 기존 ONQ / OnAirCue는 가칭, 샵캐스트 / Shopcast는 이전 선택 이력이다. 서비스명에 관한 이전 확정 문구보다 이번 결정이 우선한다.
- Streamlabs 등 벤치마킹 방향과 웹 우선 → OBS 플러그인 순서를 유지한다.

## 심볼·컬러와 용도

- 앞서 대표님이 「좋다」고 승인한 S·재생 버튼 결합 심볼과 컬러 방향을 기준으로 새 명칭의 워드마크를 반영한다.
- 키 컬러: 인디고 `#4F46E5`. 포인트: 민트 `#80E8C1`. 글자·다크 배경: 잉크 `#171A24`. 기본 배경: 클라우드 `#F7F8FC`.
- 대표님 요청에 따라 랜딩·파트너스·마스터용으로 구분한다. 랜딩은 스트림샵, 관리 영역은 스트림샵 파트너스 / 스트림샵 마스터 관리자로 표기한다.
- 기존에 제시한 용도별 이미지에는 이전 이름이 들어 있다. 스트림샵 워드마크를 반영한 최종 제작 파일과 화면 적용은 아직 완료하지 않았다.

## 반영 대상과 상태

- 제품 범위·디자인 요청문·인수인계·README에 서비스명 결정을 기록했다.
- 실제 디자인 정본과 구현의 이름·로고 교체는 후속 반영 대상이다. 문서 기록만으로 화면 반영 완료라고 보고하지 않는다.
- 교체 대상: 공개 페이지, 가입·로그인, 관리자/파트너스 화면, 오버레이 안내, 브라우저 제목·접근성 이름, 기본 브랜딩 설정, 메일, OG 공유 카드, 로고·파비콘.
- 디자인 정본과 구현을 함께 반영한다. 기존 로고의 ONQ 글자는 새 서비스명에 맞는 디자인 작업이 필요하다.
- 기존 DB 저장 브랜딩, 도메인·DNS·인증서, OAuth 콜백, 메일 발신 주소는 문구 변경과 별도로 적용 범위를 확인한다. 서비스명 결정은 운영 주소 변경 완료를 의미하지 않는다.
- 기존 코드 식별자·환경변수·과거 작업 ID·세션명은 표시용 서비스명과 구분한다.

## 아직 확정하지 않은 항목

- 새 도메인, 스트림샵 워드마크의 최종 제작 파일, 슬로건.
- 상표·도메인·동명 서비스 확인 결과. 명칭 선택은 등록 가능 여부 확인이나 상표 등록 완료를 뜻하지 않는다.
