# 서비스명: 스트림샵 (StreamShop)

> 확정일: 2026-10-07 (KST)
> 최신 대표님 지시: 「스트림샵으로 확정한다」

## 명칭 변경 이력 (2026-10-07)

- 대표님이 https://www.shopcast.kr/ 를 제시하며 같은 이름의 사이트가 있다고 알렸다.
- 명칭 선택은 있었으나 동명 서비스·상표 확인 전에 확정으로 기록하고 시안을 만든 순서가 성급했다. 브랜드 선택 이력과 실제 사용 가능 여부를 구분한다.
- 이번 직접 접속은 환경 프록시의 CONNECT 403으로 차단됐다. 사이트의 업종·운영 주체·상표 권리 상태는 확인하지 못했다. 확인한 사실처럼 추정해서 기록하지 않는다.
- 이후 대표님이 **스트림샵**으로 최종 선택했다. 샵캐스트 관련 재검토와 이전 명칭 확정 문구는 과거 기록이며 현재 서비스명은 스트림샵이다.
- 새 후보를 제안할 때는 동명 서비스·관련 업종·주요 도메인을 먼저 조사하고 상표 검색 결과와 미확인 항목을 함께 제시한다.

## 확정 표기

- 한글 서비스명: **스트림샵**
- 영문 표기: **StreamShop**
- 기존 ONQ / OnAirCue는 가칭, 샵캐스트 / Shopcast는 이전 선택 이력이다. 서비스명에 관한 이전 확정 문구보다 이번 결정이 우선한다.
- Streamlabs 등 벤치마킹 방향과 웹 우선 → OBS 플러그인 순서를 유지한다.
- 대표님 최종 도메인 지정(2026-10-10 KST): 기존 `on-aircue.com`을 유지해 운영은 `on-aircue.com`, TEST는 `dev.on-aircue.com`으로 쓴다. `streamshop.com` 구매·전환은 보류하며 서비스명 스트림샵(StreamShop)은 유지한다. 소개는 `/about`, 마스터 관리자는 `/admin`, 파트너스는 `/seller` 경로를 유지한다.

- 심볼의 모양·비율·색·음각·방향을 사용자 명시 승인 없이 변경·재생성하지 않는다. 워드마크 편집에도 심볼을 보존한다. 이름 변경을 이유로 심볼을 재설계하거나 새 심볼을 만들지 않는다.
- 제품 `components/public/Landing.tsx`와 디자인 정본 `design/project/PF-001.dc.tsx`는 같은 정본 PNG를 가져온다. 기존 표시 크기·레이아웃은 유지한다. 2026-10-10 대표님 최신 지시에 따라 PF-001 텍스트 워드마크는 끝 점 없이 `streamshop`으로 표시한다. 심볼·풀로고 원본은 변경하지 않는다.

## 반영 대상과 상태

- 제품 범위·디자인 요청문·인수인계·README에 서비스명 결정을 기록했다.
- PF-001의 TSX 정본과 `/about` 구현에 이름·심볼을 함께 적용했다. 나머지 화면의 이름·로고 교체는 후속이며 전면 반영 완료로 보고하지 않는다.
- 공개 공통 머리·꼬리의 로고는 승인 보라 심볼과 점 없는 `streamshop`으로 통일한다: `/features`, `/pricing`, `/faq`, `/notices`, `/notices/[noticeId]`, `/terms`, `/privacy`와 같은 공통 틀을 쓰는 가입 신청 5단계. 쇼핑몰별 로고·저장 브랜딩은 이 교체 범위에 포함하지 않는다.
- 교체 대상: 공개 페이지, 가입·로그인, 관리자/파트너스 화면, 오버레이 안내, 브라우저 제목·접근성 이름, 기본 브랜딩 설정, 메일, OG 공유 카드, 로고·파비콘.
- 디자인 정본과 구현을 함께 반영한다. 기존 로고의 ONQ 글자는 새 서비스명에 맞는 디자인 작업이 필요하다.
- 기존 DB 저장 브랜딩, 도메인·DNS·인증서, OAuth 콜백, 메일 발신 주소는 문구 변경과 별도로 적용 범위를 확인한다. 서비스명 결정은 운영 주소 변경 완료를 의미하지 않는다.
- 기존 코드 식별자·환경변수·과거 작업 ID·세션명은 표시용 서비스명과 구분한다.

## 아직 확정하지 않은 항목

- 슬로건. 승인 풀로고 제작 파일은 위 정본으로 확정했으며 화면별 적용은 후속이다.
- 기존 도메인 관리 화면은 확인했으나 새 TEST DNS·HTTPS와 서버 적용, 운영 대상 서버 확인은 별도다. 도메인 지정은 적용 완료를 뜻하지 않는다.
- 상표·도메인·동명 서비스 확인 결과. 명칭 선택은 등록 가능 여부 확인이나 상표 등록 완료를 뜻하지 않는다.
