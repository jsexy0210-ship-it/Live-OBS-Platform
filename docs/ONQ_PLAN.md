## 반드시 넣을 부정·보안 시험

- 지원 목록 밖 쇼핑몰 주소로 자동 연결 구매 시도: 결제 기록·작업이 하나도 생기지 않고 무료 직접 설정 안내만 나오는지
- 직원(대표자 아님)이 자동 연결 구매·시작·취소·재개·환불 요청 시 403이고 결제·작업·외부 변경 0건
- 연동 자격증명: DB에 평문 토큰 0건, 로그에 토큰 0건, 다른 판매자로 쓰려 하면 거부, 연동 해제·해지 뒤 토큰 0건이고 그 토큰으로 쇼핑몰 API 호출 불가
- 비로그인으로 판매자·관리자·결제 완료·자동화 실행 주소 접근, 오버레이 계정의 통합 기능, 판매자의 마스터 기능 접근
- 판매자·주문·작업 ID 바꿔치기, 결제 성공 URL 위조, 과거 결제·인증 재사용, 로그아웃·권한 회수 뒤 열린 탭
- 공개 오버레이 토큰 범위·회수·개인정보 최소화
- 쇼핑몰 주소 확인(서버가 판매자 입력 주소에 접속): http·https와 기본 포트만 허용, DNS 확인 뒤와 리다이렉트마다 IP를 다시 검사해 공인 주소가 아니면 모두 거부(IPv4: 0/8·10/8·100.64/10·127/8·169.254/16·172.16/12·192.168/16·멀티캐스트 등, IPv6: ::1·fe80::/10·fc00::/7·IPv4 매핑 주소), 실제 연결한 상대 IP를 확인한 IP로 고정(재해석 금지)해 DNS 바꿔치기를 막음, 리다이렉트 횟수 상한. DNS 바꿔치기·IPv6 내부 주소도 시험. 이런 주소로 접속을 유도하는 입력이 모두 거부되고 내부 요청이 0건인지
- 플랫폼 이름 노출 0건: 화면·API 응답(필드·오류)·메일·알림·영수증·운영 메시지를 수집해 외부 플랫폼 이름·로고·내부 식별자 검색 0건
- 외부 쇼핑몰 주문 개인정보: 권한 없는 직원·다른 판매자 조회 거부, 오버레이·로그·권한 없는 역할 마스킹(권한 있는 주문 화면은 원문), 보관 기간(원본 이벤트 받은 날+30일, 주문 처리 끝난 날+90일, 끝나지 않은 주문은 받은 날+90일, 확정값 기준)이 지난 주문과 그 주문의 원본 웹훅 이벤트·재시도·실패 보관본(데드레터)까지 자동 삭제
- 외부 쇼핑몰 웹훅 서명·토큰이 없거나 틀리거나 다른 판매자 것이면 거절되고 주문·이벤트가 하나도 저장되지 않는지
