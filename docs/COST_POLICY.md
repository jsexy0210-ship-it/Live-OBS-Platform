# 비용 부담 주체 정본 (2026-10-05 대표님 결정)

비용 주체 용어는 **마스터 관리자 / 파트너스 / 구매자** 3개만 쓴다. 「플랫폼 부담」 같은 표현은 쓰지 않는다.

## 원칙

마스터 관리자는 서비스 공통 인프라·운영비와 구독에 포함된 기본 제공량을 부담한다. 특정 파트너스의 선택 또는 사용량으로 외부 업체의 건당 비용이 발생하는 기능은 해당 파트너스의 선불 충전금(**발송·이용 충전금**)에서 차감한다. 구매자에게는 상품대금·배송비 및 구매자 귀책에 따른 교환·반품 배송비 외의 시스템·API·인증·발송·송장 관련 기술 비용을 별도로 전가하지 않는다.

## 발송·이용 충전금 (기존 「발송 충전」을 이름 변경)

차감 대상: 거래 메일 초과분 · 대량 메일 · SMS/LMS · 알림톡 · 구매자 본인확인 · 배송 자동조회 · 송장 발급 API · 송장 라벨 API · 현금영수증 API · 전자세금계산서 API. 잔액이 없으면 해당 기능만 멈추고 주문 처리는 계속한다. 후불 청구 없음.

## 현금영수증·전자세금계산서 발행 명의 (2026-10-05 대표님 결정)

구매자 상품 결제의 현금영수증·전자세금계산서는 **파트너스 명의**로 발행한다. 외부 발행 업체 API를 쓰고, 플랫폼 명의 결제대행사 현금영수증은 쓰지 않는다. 건당 비용은 파트너스 발송·이용 충전금에서 차감한다. 파트너스별 발행자 정보(사업자 정보)를 받아 둔다.

## 외부 서비스 업체 선택 (2026-10-05 대표님 지시)

- 업체 선택은 마스터 관리자, 기능 사용 여부는 파트너스, 구매자는 결과만 이용한다. 파트너스 화면에 업체 이름을 고르게 하지 않고 기능 켜기·끄기와 건당 단가·이번 달 사용량·금액만 보여 준다.
- 마스터 관리자 「설정 > 외부 서비스 연동」에서 분야별(결제·PG, 배송·송장) 국내 업체를 여러 개 등록하고 카드로 비교한다(셀렉트 박스 아님). 카드에는 기능 지원 여부·비용·ONQ 점수·「상세 비교」「선택」 버튼.
- 업체 카드는 업체 로고 중심으로 디자인한다(2026-10-05 대표님 지시). 로고는 마스터 관리자가 업체마다 올리는 이미지(PNG·SVG, 플랫폼 저장소 보관, 외부 주소 직접 연결 금지)이며, 없으면 업체 이름 첫 글자 표시로 대신한다. 로고는 각 업체의 공식 배포 이미지·사용 지침을 따른다.
- `추천` 배지는 하드코딩하지 않고 마스터 관리자가 바꾼다. 점수는 아래 가중치로 계산하고 가중치도 설정에서 바꾼다.
  - PG: 수수료 30 · 초기/고정비 15 · 정기결제 15 · 결제수단 15 · API/개발 편의 10 · 안정성 10 · 정산주기 5
  - 배송: 송장 발급 20 · 송장 출력 15 · 배송 추적 20 · 택배사 범위 15 · 반품 연동 10 · 비용 10 · API 품질 10
- 초기 추천: PG = NICEPAY(1순위, 후보 토스페이먼츠·NHN KCP·KG이니시스·페이플), 통합 배송·송장 = 굿스플로(1순위), 배송조회 전용 = 스마트택배(스윗트래커, 보조), 택배사 직접 연동은 대량 운영용 조건부.
- 업체 정보의 수수료·요금은 공개 기준 참고값이며 실제 계약 조건은 계약 때 확인한다. 업체 계약·유료 연동은 대표님 승인 뒤(유료 서비스 원칙). 결제는 플랫폼 결제대행사 키 하나 원칙 유지.
