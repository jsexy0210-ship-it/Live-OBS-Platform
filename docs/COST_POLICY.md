# 비용 부담 주체 정본 (2026-10-05 대표님 결정)

비용 주체 용어는 **마스터 관리자 / 파트너스 / 구매자** 3개만 쓴다. 「플랫폼 부담」 같은 표현은 쓰지 않는다.

## 원칙

마스터 관리자는 서비스 공통 인프라·운영비와 구독에 포함된 기본 제공량을 부담한다. 특정 파트너스의 선택 또는 사용량으로 외부 업체의 건당 비용이 발생하는 기능은 해당 파트너스의 선불 충전금(**발송·이용 충전금**)에서 차감한다. 구매자에게는 상품대금·배송비 및 구매자 귀책에 따른 교환·반품 배송비 외의 시스템·API·인증·발송·송장 관련 기술 비용을 별도로 전가하지 않는다.

## 발송·이용 충전금 (기존 「발송 충전」을 이름 변경)

차감 대상: 거래 메일 초과분 · 대량 메일 · SMS/LMS · 알림톡 · 구매자 본인확인 · 배송 자동조회 · 송장 발급 API · 송장 라벨 API · 현금영수증 API · 전자세금계산서 API. 잔액이 없으면 해당 기능만 멈추고 주문 처리는 계속한다. 후불 청구 없음.

## 현금영수증·전자세금계산서 발행 명의 (2026-10-05 대표님 결정)

구매자 상품 결제의 현금영수증·전자세금계산서는 **파트너스 명의**로 발행한다. 외부 발행 업체 API를 쓰고, 플랫폼 명의 결제대행사 현금영수증은 쓰지 않는다. 건당 비용은 파트너스 발송·이용 충전금에서 차감한다. 파트너스별 발행자 정보(사업자 정보)를 받아 둔다.
