## 3. UX Writing

### 3.1 기본 규칙

모든 사용자 노출 문구의 기본 형태:

**명사형 종결**

금지:

- 감성적 위로
- 장문 설명
- 질문형 CTA
- 과장된 공포
- 근거 없는 가치판단

우선:

- 숫자
- 단위
- 기준
- 상태
- 출처

예시:

| 기존 표현 | 적용 표현 |
|---|---|
| 앞으로 몇 번 더 출근해야 할까요? | 출근 잔량 |
| 지금까지 얼마를 썼을까요? | 누적 구독료 |
| 자세히 보기 | 계산 근거 |
| 다시 계산하기 | 재계산 |
| 다른 것도 계산해보기 | 다른 잔량 |
| 데이터를 불러오지 못했습니다 | 데이터 조회 실패 |
| 값을 다시 확인해주세요 | 입력값 확인 필요 |
| 저장되었습니다 | 저장 완료 |

### 3.1-1 입력·숫자 표기

- 범위가 정해진 값(나이·연도·요일수·휴가일·시간) · 드롭다운
- 직접 입력 값(금액·서비스명) · 텍스트 입력, 천 단위 콤마 자동
- 금액 100만원 이상 · 만원 단위 절사 표기 (입력 필드 아래 환산 표기 포함)
- 날짜 · 입력 영역 전체 클릭 → 년/월/일 3단 휠 피커
- 결과 숫자 · 한 줄 고정, 넘치면 글자 크기 자동 축소

### 3.2 결과 문법

공통 순서:

1. 핵심 숫자
2. 결과 명칭
3. 팩트 배지
4. 임팩트 배지
5. 차트
6. 세부 수치
7. 계산 근거
8. 데이터 출처
9. 결과 공유
10. 다른 잔량

예시:

```text
4,218회
남은 출근

[잔량 18%] [퇴직 가시권]

소모 82%
잔량 18%

기준일 2026.09.21
계산 유형 공식 일정 기반
```

## 4. 배지 시스템

배지 원칙:

**판정 근거는 숫자 / 표현만 자극적**

### 4.1 공통 잔량 배지

| 잔량 | 팩트 | 임팩트 |
|---:|---|---|
| 75% 이상 | 잔량 75%+ | 초반 구간 |
| 50~75% | 잔량 50%+ | 아직 여유 |
| 25~50% | 잔량 절반 이하 | 중반 소진 |
| 10~25% | 잔량 25% 미만 | 막판 진입 |
| 10% 미만 | 잔량 10% 미만 | 종료 임박 |
| 5% 미만 | 잔량 5% 미만 | 한계 구간 |

### 4.2 생존 잔량

| 기간 | 배지 |
|---:|---|
| 12개월 이상 | 현금 방어 충분 |
| 6~12개월 | 완충 구간 |
| 3~6개월 | 단기 방어 |
| 1~3개월 | 생존 압박 |
| 1개월 미만 | 현금 바닥 임박 |

### 4.3 섹션별 임팩트 사전

출근:
- 출근 초반
- 절반 소진
- 퇴직 가시권
- 출근 종료 임박

월급:
- 급여 여유
- 급여 절반
- 월급 막판
- 월급 종료 임박

시간:
- 시간 누적
- 개월 단위 소모
- 1년급 소모
- 인생 단위 소모

구독:
- 구독 누적
- 연 100만원 초과
- 연 300만원 초과
- 구독비 고정비화

금지:
- 망함
- 인생 끝
- 죽음 임박
- 개인의 실제 수명 단정
- 근거 없는 과소비 판정
