# Streamlabs 벤치마킹 기준

> 결정일: 2026-10-07 (KST)
> 근거: 대표님 지시 「이 사이트 기억해놔 비슷하게 가고 최대한 벤치마킹한다」
> 개발 순서: 「일단 웹부터 진행하고 그다음 이어서 해본다」

## 확정 방향

- 전체 후보 16개의 국내·해외 구분과 적용 항목은 [벤치마킹 사이트 전체 목록](REFERENCE_SERVICES.md)에 기록한다.
- Streamlabs를 주요 제품·사용 경험 벤치마킹 대상으로 유지한다.
- 웹 버전을 먼저 진행하고, 이후 OBS 플러그인으로 확장하는 순서로 간다.
- 공개 사이트, 기능 소개, 회원가입과 시작 안내, 요금 비교, 오버레이·위젯 설정, 방송 도구를 연결하는 경험을 최대한 참고한다.
- 우리 제품의 판매자별 쇼핑몰·주문·재고·배송·방송 운영 흐름에 맞게 적용한다.

| 도움말 | 작업별 가이드·FAQ·지원 진입 | 연결 오류·주문 수신·OBS 표시 문제를 단계별 해결 |
| 이후 확장 | 기존 OBS에서 사용하는 플러그인 | 웹 안정화 이후 주문 패널·연결·오버레이 자동 설정 검토 |

## 적용과 인수인계 원칙

- 새 화면 설계와 관련 화면 개선 시 참고한 Streamlabs 페이지 및 우리 서비스에 적용한 항목을 남긴다.
- 화면별 변경은 디자인 정본과 실제 구현에 함께 반영하고 기존 디자인 동기화 절차를 따른다.
- 위젯·테마·동시 송출·AI·편집 등 각 기능의 실제 구현 범위와 순서는 개별 작업으로 구체화한다. 이번 지시만으로 모든 Streamlabs 제품의 출시 범위·가격·일정을 확정한 것으로 기록하지 않는다.
- 이후 세션에서도 `PRODUCT_SCOPE.md`와 `HANDOFF.md`를 통해 이 기준을 이어받는다.

## 조사 상태 (2026-10-07)

- 공개 Ultra·FAQ·OBS 플러그인·테마·위젯·동시 송출 등 주요 제품 설명을 확인했다.
- 공식 FAQ 기준 Ultra는 월 $27 또는 연 $189다. 향후 가격 비교 시 다시 확인한다. 우리 요금을 자동으로 변경하는 기준은 아니다.
- 가입 진입 주소는 확인했으나 로그인 후 대시보드, 실제 가입·구매·해지, 설치 및 송출 동작은 검증하지 않았다. 해당 화면을 실제 관찰한 것처럼 설계 근거로 기록하지 않는다.
- 국내 유사 서비스의 최신 요금·운영 상태는 일부 공식 사이트 접속 제한으로 확인이 남아 있다.
