# 파트너스 발송·인증·조회 비용 안내 서식

- 대상: 파트너스(판매자). 파트너스 관리자의 「발송·이용 충전」 화면, 첫 충전 전 동의 화면, 파트너스 이용약관의 발송 비용 조항에 그대로 쓴다.
- 결정: 2026-10-05 대표님 결정. 건당 비용이 드는 발송은 판매자 선불 충전으로 처리하고, 후불 청구는 하지 않는다. 비용 부과 내용은 판매자에게 명확히 알리고 동의를 받는다. 플랫폼 운영자에게 손해가 생기지 않게 한다.
- 참고한 업계 방식:
  - 카페24: 문자·알림톡은 판매자가 선불로 충전하고 보낼 때마다 차감한다. 환불은 유료 잔여분에서 수수료 10%를 빼고 하며, 무상으로 준 건수는 환불하지 않는다.
  - 카카오 비즈메시지(알림톡): 성공한 건만 과금한다. 알림톡이 실패해 문자로 대신 보내면 최종으로 성공한 채널 요금만 받는다.
  - 네이버 스마트스토어: 기본 주문 알림은 플랫폼 수수료 안에서 처리한다. 판매자가 따로 보내는 메시지는 판매자가 외부 업체에 직접 낸다.
- 법률 확인: 출시 전에 법률 검토를 받는다. 특히 환불 수수료, 책임 제한, 잔액 소멸은 약관규제법상 판매자에게 지나치게 불리하면 무효가 될 수 있다.
- 화면 말투: 파트너스 관리자 화면 규칙인 합니다체를 쓴다.
- `{{ }}`로 표시한 값은 마스터 관리자 설정값으로 채운다.

## 1. 무료·유료 항목

| 구분 | 비용 | 기준 |
|---|---|---|
| 주문·배송 안내 메일(거래 메일) | 구독 플랜에 포함 | 플랜별 월 제공량 `{{월 거래 메일 제공량}}`통까지 무료입니다. 남은 제공량은 다음 달로 넘어가지 않습니다. |
| 제공량을 넘은 거래 메일 | 발송·이용 충전금에서 차감 | 1통당 `{{거래 메일 단가}}`원 |
| 광고·공지 대량 메일 | 발송·이용 충전금에서 차감 | 1통당 `{{대량 메일 단가}}`원 |
| 문자(SMS·LMS) | 발송·이용 충전금에서 차감 | 1건당 `{{문자 단가}}`원(긴 문자는 `{{LMS 단가}}`원) |
| 알림톡 | 발송·이용 충전금에서 차감 | 1건당 `{{알림톡 단가}}`원 |
| 구매자 휴대폰 본인인증 | 발송·이용 충전금에서 차감 | 쇼핑몰 가입·찾기에서 본인인증을 켠 경우 1건당 `{{본인인증 단가}}`원. 끄면 비용이 없습니다. 인증에 실패한 건은 차감하지 않습니다. |
| 배송 자동 조회 | 발송·이용 충전금에서 차감 | 「배송 완료 자동 처리」를 켠 경우 송장 1건 조회당 `{{배송 조회 단가}}`원. 끄면 구매자에게 택배사 조회 페이지 링크만 보여 드리며 비용이 없습니다. |
| 송장 발급·송장 라벨 API | 발송·이용 충전금에서 차감 | 외부 업체가 건당 요금을 받는 경우에만 건당 차감합니다. 송장번호 직접 입력과 송장 관리 화면은 비용이 없습니다. |
| 현금영수증·전자세금계산서 API | 발송·이용 충전금에서 차감 | 외부 업체가 건당 요금을 받는 경우에만 건당 차감합니다. |

- 표시한 단가는 부가가치세 `{{포함/별도}}` 금액입니다.
- 파트너스 가입, 직원 연결, 파트너스 아이디·비밀번호 찾기의 본인인증은 마스터 관리자가 부담합니다. 남용을 막기 위해 하루 횟수를 제한합니다.
- 위 표에 없는 발송에는 비용을 받지 않습니다. 새로 비용을 받으려면 아래 6번 절차를 거칩니다.

## 2. 선불 충전 방식

1. 유료 발송은 미리 충전한 잔액에서만 차감합니다. 후불 청구, 외상, 잔액이 마이너스가 되는 일은 없습니다.
2. 잔액이 모자라면 그 건은 보내지 않고 「잔액 부족 미발송」으로 기록합니다. 주문·배송 처리 자체는 그대로 진행됩니다.
3. 잔액이 `{{잔액 부족 알림 기준}}`원 아래로 내려가면 파트너스 관리자 화면과 메일로 알려 드립니다.
4. 충전하면 결제 영수증을 발행합니다. 세금계산서가 필요하면 충전 때 신청하십시오.

## 3. 차감 기준

1. 받는 사람에게 도달에 성공한 건만 차감합니다. 실패한 건은 차감하지 않으며, 먼저 차감했다면 되돌립니다.
2. 알림톡이 실패해 문자로 대신 보내면, 최종으로 성공한 채널 요금 하나만 차감합니다. 이중으로 차감하지 않습니다.
3. 같은 발송 요청이 두 번 들어와도 한 번만 차감합니다.
4. 차감·충전 내역은 「발송·이용 충전 → 사용 내역」에서 건별로 확인할 수 있습니다. 내역에 이의가 있으면 차감일로부터 `{{이의 제기 기간}}`일 안에 고객센터로 알려 주십시오. 확인 후 잘못 차감된 금액은 잔액으로 돌려 드립니다.

## 4. 환불

1. 직접 충전한 잔액(유료 잔액)은 환불을 신청할 수 있습니다. 환불 금액은 유료 잔액에서 환불 수수료 `{{환불 수수료율}}`%를 뺀 금액입니다.
2. 이벤트·보상으로 무상 지급한 잔액은 환불하지 않습니다. 차감은 유료 잔액에서 먼저 하고, 유료 잔액이 없으면 무상 잔액에서 합니다.
3. 구독을 해지하거나 탈퇴할 때 남은 유료 잔액은 위 1번 기준으로 환불합니다.
4. 결제 후 `{{청약 철회 기간}}`일 안에 전혀 쓰지 않은 충전은 수수료 없이 전액 환불합니다.

## 5. 판매자 책임

1. 발송 내용과 받는 사람 선택은 판매자 책임입니다. 광고성 메시지를 보낼 때는 정보통신망법 제50조에 따라 받는 사람의 수신 동의, 「(광고)」 표시, 수신 거부 방법, 야간(21시~다음 날 8시) 발송 제한을 지켜야 합니다. 이를 지키지 않아 생긴 과태료·분쟁·손해는 판매자가 부담합니다.
2. 스팸 신고나 카카오·통신사 정책 위반으로 발송이 막히거나 발신번호가 차단되면, 그동안 쓴 비용은 돌려 드리지 않습니다.
3. 잔액 부족, 판매자가 끈 설정, 받는 사람 정보 오류로 보내지 못한 메시지 때문에 생긴 손해는 플랫폼이 책임지지 않습니다. 다만 플랫폼의 고의나 중대한 과실로 생긴 손해는 예외입니다.
4. 외부 발송 업체(메일·문자·카카오)의 장애로 보내지 못한 건은 차감하지 않습니다. 그 밖의 손해는 플랫폼의 고의나 중대한 과실이 없으면 책임지지 않습니다.

## 6. 단가와 제공량 변경

1. 단가를 올리거나 제공량을 줄일 때는 적용 `{{불리한 변경 사전 공지 일수}}`일 전에 파트너스 관리자 공지와 메일로 알립니다. 단가를 내리거나 제공량을 늘릴 때는 적용 `{{유리한 변경 사전 공지 일수}}`일 전에 알립니다.
2. 이미 충전한 잔액은 금액(원) 기준이라 사라지지 않습니다. 변경 후 발송부터 새 단가로 차감합니다.
3. 변경에 동의하지 않으면 적용일 전에 유료 잔액 환불을 신청할 수 있습니다. 이때는 환불 수수료를 받지 않습니다.

## 7. 동의

- 첫 충전 전 「발송 비용 안내를 확인했고 동의합니다」 체크를 받습니다. 체크하지 않으면 충전할 수 없습니다.
- 동의한 안내 서식의 버전과 시각을 저장합니다. 6번에 따라 내용이 바뀌면 다음 충전 때 다시 동의를 받습니다.

## 구현 조건(개발 참고, 화면에는 싣지 않는다)

- 충전 잔액 원장: 유료와 무상을 구분하고, 음수가 되지 않으며, 동시에 차감해도 안전하게 한 번만 차감한다. 성공 확인 뒤 확정하고, 실패하면 되돌린다.
- 동의 기록: 서식 버전, 시각, 판매자 직원 ID를 남긴다.
- 단가와 제공량 변경: 최고관리자만 하고 로그 추적에 남긴다. 적용 예정일을 두고 공지 발송과 연결한다.
- 이 서식의 `{{ }}` 값이 정해지고 법률 검토가 끝나기 전에는 충전 기능을 켜지 않는다.
