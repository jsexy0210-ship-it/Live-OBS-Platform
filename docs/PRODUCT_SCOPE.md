# Product Scope

## 목표

판매자별 쇼핑몰과 라이브 방송 운영을 하나로 제공하는 구독 플랫폼.

## 기능 범위

### 쇼핑몰

- 판매자별 쇼핑몰
- 상품·이미지·재고 관리
- 주문 관리
- 판매자 명의 PG 연결 (플랫폼이 대금을 수취하지 않는 구조 전제)

### 라이브 운영

- 방송 주문 대기열
- OBS 오버레이
- HIT 표시
- 주문자 알림

## 참조

- 망고TCG 소스(`jsexy0210-ship-it/obs-order-queue-cafe24-webhook`)를 기능 참조로 활용한다.
- 원본 저장소·운영 DB·설정은 변경하지 않는다. 운영 데이터·비밀정보는 가져오지 않는다.

## 가격

- 월 99,000원: **현재 제안가** (확정 아님)

## 미확정

- 요금제별 제공량 (판매자 수, 상품 수, 이미지 용량, 주문 건수, 방송 시간 등)
- 지원 범위 (응대 채널·시간, 초기 세팅 지원 여부)
- PG사 범위 및 연결 방식
- 알림 채널 (카카오 알림톡, SMS 등)
- 데이터 저장소·이미지 버킷 구성
- 운영 도메인
