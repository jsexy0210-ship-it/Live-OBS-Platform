# Product Scope

## 목표

판매자별 쇼핑몰과 라이브 방송 운영을 하나로 제공하는 구독 플랫폼.

## 기능 범위

### 쇼핑몰

- 판매자별 쇼핑몰
- 쇼핑몰 주소 (2026-10-02 대표님 결정): 가입 즉시 플랫폼 하위 기본 주소 제공 + 판매자가 직접 산 도메인(.com, .co.kr 등) 연결. 판매자가 도메인 회사에 연결 값을 넣고 플랫폼이 소유 확인 후 보안 인증서를 자동 발급
- 상품·이미지·재고 관리
- 주문 관리
- 구매자 → 판매자 문의 (2026-10-02 대표님 지시): 상품 문의(상품 상세에서, 공개·비공개 선택)와 1:1 문의(마이페이지). 판매자가 관리자에서 답변하고, 답변이 달리면 구매자에게 알림. 해당 판매자와 마스터만 볼 수 있고 다른 판매자는 볼 수 없음
- 판매자 명의 PG 연결 (플랫폼이 대금을 수취하지 않는 구조 전제)
- 구매자 계정 (2026-10-02 대표님 확정): 회원만 주문할 수 있다(비회원 주문 없음). 회원가입 시 PASS 본인인증 필수 (2026-10-02 대표님 지시). 판매자 가입 신청 시 대표자도 PASS 본인인증. 대표자 1명은 쇼핑몰 1개만 열 수 있다(대표자 CI 기준, 해지된 쇼핑몰은 제외. 2026-10-02 대표님 지시). 본인인증 결과(CI)로 같은 쇼핑몰 중복 가입을 막는다
- 로그인 (2026-10-02 대표님 결정): 마스터·판매자·구매자 모두 아이디(이메일)와 비밀번호가 맞으면 바로 로그인한다. 2단계 인증, 로그인 실패 잠금, 접속 IP·네트워크 제한(지정 IP)은 두지 않는다. 로그인 실패는 감사 로그에 남긴다. 판매자 비밀번호 찾기는 대표자 PASS 본인인증으로 하고, 인증한 사람이 그 쇼핑몰 대표자와 같으면(CI 일치) 바로 새 비밀번호를 입력한다. 메일 링크는 쓰지 않는다. 직원 계정은 대표자가 직원 계정 관리에서 재설정한다.
- 구매자 알림 (2026-10-02 대표님 확정): 카카오 알림톡으로 보내고 실패하면 문자로 대신 보낸다. 「내 차례 알림」은 두지 않는다(대표님 결정 2026-10-02 변경)
- 구매자 메일 (2026-10-02 대표님 결정): 알림톡·문자와 함께 가입 이메일로 주문 메일을 보낸다. 종류는 주문 완료 · 발송(송장 조회 버튼) · 배송 완료 · 취소·환불 4가지. 받는 분 이름·연락처·주소는 가리지 않고 그대로 보여 준다(대표님 결정). 문구는 해요체. 판매자가 종류별로 켜고 끌 수 있다(SA-080). 메일 발송 업체·비용은 대표님 승인 대상
- 개인정보 표시 (2026-10-02 대표님 결정): 판매자·마스터 관리 화면(주문, 배송, 회원, 문의 등)과 주문 메일에서 구매자 이름·연락처·주소를 가리지 않고 그대로 보여 준다. 열람·내보내기는 감사 로그에 남긴다. 다른 구매자에게 공개되는 화면(상품 문의 작성자 등)은 방송 닉네임만 보여 준다
- 판매자 직원 계정 (2026-10-02 대표님 결정): 고정 역할(매니저·방송 담당)로 나누지 않고 권한 항목으로 나눈다. 쇼핑몰 대표자가 직원 계정을 직접 만들고, 항목별로 권한을 켜고 끈다. 항목: 방송 진행(주문대기·개봉) · 오버레이 편집 · 상품 · 주문·배송 · 고객 정보 보기(이름·연락처·주소) · 회원·적립금 · 문의 답변 · 영수증·세금계산서 · 매출 보기 · 쇼핑몰 설정. 결제(PG) 연결·구독·직원 관리·실지급 스위치는 대표자만. 자주 쓰는 묶음(예: 「방송만」)은 버튼으로 한 번에 고를 수 있다. 권한 변경은 감사 로그에 남긴다
- 판매자 가입 순서 (2026-10-02 대표님 결정): 가입 신청 → 마스터 승인 → 승인 안내(메일·알림톡) → 판매자 로그인 → 무료 이용 → 무료 기간이 끝나면 구독 결제 후 계속 사용. 로그인 아이디(이메일)와 비밀번호는 판매자가 가입 신청 때 직접 정한다(플랫폼이 초기 비밀번호를 만들어 주지 않는다). 승인 안내에는 판매자 관리자 주소와 로그인 이메일, 다음 할 일을 담는다. 첫 로그인 때 「시작하기」 체크리스트(쇼핑몰 정보 → PG 연결 → 상품 등록 → 오버레이 주소 복사)를 보여 준다
- 무료 이용 (2026-10-02 대표님 결정): 가입 신청일부터 3일 동안 무료로 쓴다. 3일이 지나면 구독을 결제해야 판매자 관리자 기능을 계속 쓸 수 있다(결제 전에는 구독·결제 화면과 로그아웃만 열림). 결제하면 바로 이어서 쓴다
- 판매 방식과 환불 고지 (2026-10-02 대표님 결정): 유튜브 라이브에서 판매자가 구매자 대신 개봉(대리 개봉)하고, 상품은 개봉된 상태로 배송한다. 그래서 「개봉하면 환불 불가」 안내와 결제 전 동의 체크는 두지 않는다. 개봉 전 주문 취소는 그대로 가능하다
- 무통장 입금·구매 제한 기본값 (2026-10-02 MASTER 결정, 판매자가 바꿀 수 있음): 입금 기한은 주문 후 24시간, 기한이 지나면 자동 취소(재고 복구), 기한 1시간 전 알림. 자동 구매 제한은 「미입금 자동 취소 3회 → 30일 주문 막기」 켜짐, 「결제 후 취소 5회 → 30일」 꺼짐. 구매 제한은 주문만 막는다(유튜브 채팅은 플랫폼이 막을 수 없음)

### 적립금 (판매자별)

- 신규 개발. 망고TCG 적립금 기능은 참고만 하고 코드는 이식하지 않음
- 판매자별 적립금 정책: 회원 등급별 적립률(카드/무통장 구분), 지급 시작 시점
- 주문 결제 완료 시 지급, 취소·환불 시 회수 (자동/수동 회수 모드)
- 판매자별 적립금 원장(지급·회수·실패 이력)과 회원별 잔액
- 구매 랭킹 보너스: 명예의 전당 1위 적립금 보너스는 판매자가 켜고 금액을 정한다 (기본 꺼짐, 2026-10-02 대표님 확정)
- 실지급은 판매자별 실행 스위치(기본 꺼짐)로 통제. 개발·검증 단계에서는 테스트 모드만 사용

### 세금계산서·현금영수증 (2026-10-02 대표님 지시)

- 구매자 → 판매자 쇼핑몰: 무통장·계좌이체 결제 시 주문서에서 현금영수증 신청(소득공제용 휴대폰 번호 / 지출증빙용 사업자등록번호). 사업자 구매자는 세금계산서 신청(사업자 정보 입력). 카드 결제는 카드 매출전표로 대신해 별도 발행하지 않는다
- 발행 주체는 판매자(판매자 명의). 판매자 관리자에서 신청 목록·발행 상태(대기 · 발행 · 실패 · 취소)를 보고, 환불 시 발행 취소(마이너스 발행)를 함께 처리
- 플랫폼 → 판매자: 구독료 세금계산서를 플랫폼 명의로 매월 자동 발행. 마스터 콘솔에서 발행 내역·실패·재발행 관리
- 발행 연동 방식(PG 부가 기능 · 발행 대행 서비스 API · 홈택스 수동)은 미확정 (유료, 대표님 승인)

### 배송·정책 결정 (2026-10-02 대표님 확정, 근거 `docs/FEATURE_GAP.md`)

- 배송: 구매자가 주문할 때 「즉시 발송」 또는 「보관 후 합배송」을 고른다. MVP는 즉시 발송(배송지·배송비·도서산간·송장 입력·발송 알림), 보관·합배송(보관 기한 포함)은 출시 후 1차
- 미성년자 구매: 판매자가 「미성년자 구매 막기」 / 「고지 후 허용」 중 선택(기본 고지 후 허용). PASS 생년월일로 판별, 주문서에 미성년자 취소권 고지
- 방송 시작 알림: 광고성 정보로 보고 마케팅 수신 동의 회원에게만 보낸다. 문구에 (광고) 표기와 수신 거부 방법 포함
- 알림톡·문자·가상계좌 등 건당 비용: 전부 판매자 부담(충전식). 요금제에 포함하지 않는다

### 라이브 운영

- 판매자 방송 대시보드는 Ctrl 조합 키보드 단축키로 개봉 시작·완료, HIT 등록, 타이머 조정, 취소를 할 수 있다 (2026-10-02 대표님 지시). 입력창 입력 중에는 동작하지 않고, 취소는 확인 후 실행
- 방송 주문대기
- OBS 오버레이 편집기: 판매자가 위젯 위치(드래그 앤 드롭)·크기·모든 속성을 직접 편집, 스냅·스마트 가이드 제공 (2026-10-02 대표님 지시)
- OBS 오버레이: 세로 9:16(1080×1920)·가로 16:9(1920×1080) 두 비율, OBS 캔버스·유튜브 라이브 실제 크기와 일치, 기본 템플릿 3종 제공 (2026-10-02 대표님 지시)
- HIT 표시
- 주문자 알림

### 판매자 도우미 (2026-10-02 대표님 지시)

- Gemini API 기반 질문·답변 채팅. 판매자 관리자 안에서만 쓴다.
- 플랫폼 사용법에 대해서만 답한다 (2026-10-02 대표님 확정: 판매자 본인 데이터 조회 답변은 하지 않음). 마스터가 등록한 답변 근거 문서 안에서 답하고, 범위 밖 질문은 정중히 거절하고 문의하기로 안내한다.
- 답변만 한다. 주문 변경·설정 변경·결제 같은 실행 기능은 없다.
- 구매자 개인정보·결제정보·비밀값은 Gemini로 보내지 않는다.

### 플랫폼 마스터 관리자

- **플랫폼 마스터 관리자가 최상위 권한이다. 권한 계층: 마스터 관리자 > 판매자 > 구매자·시청자. 마스터 콘솔은 모든 판매자·쇼핑몰·구독·설정을 다루며, 판매자 권한으로 마스터 콘솔 기능에 접근할 수 없다. 마스터 콘솔 안에서도 역할별 권한을 나눈다: 무제한 조회·변경은 최고관리자(대표님)만, 운영·CS는 담당 기능만, 조회 전용은 변경 불가.** (2026-10-02 대표님 지시)
- 대표·플랫폼 운영팀 전용 통합 관리 콘솔 (판매자 관리자와 분리)
- 판매자 가입 승인·정지, 판매자별 쇼핑몰·구독·PG 연결·방송 현황 조회
- 요금제·구독·구독료 청구 관리, 결제 실패·연체 관리
- 고객지원(문의·공지), 관리자 계정·역할별 권한, 감사 로그
- 판매자 화면 대리 조회는 읽기 전용, 접근 기록 필수

## 참조

- 망고TCG 소스(`jsexy0210-ship-it/obs-order-queue-cafe24-webhook`)를 기능 참조로 활용한다.
- 원본 저장소·운영 DB·설정은 변경하지 않는다. 운영 데이터·비밀정보는 가져오지 않는다.

## 가격

- 정가 월 300,000원, 할인가 월 199,000원으로 표기한다 (2026-10-02 대표님 결정). 요금 안내·구독 결제 화면에 정가는 취소선, 할인가를 크게 보여 준다. 실제 청구액은 199,000원
