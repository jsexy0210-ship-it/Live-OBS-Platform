# 디자인 프롬프트 (클로드디자인용)

> 작성일: 2026-10-02 (KST)
> 용도: 클로드디자인에 그대로 붙여넣는 화면 디자인 요청문
> 상태: 디자인 결과 대기. 결과가 나오면 공유 링크·파일을 이 문서 하단 "결과"에 기록한다.

```text
[프로젝트]
Live OBS Platform — 판매자별 쇼핑몰과 라이브 방송 운영을 하나로 제공하는 구독형 SaaS.
판매자는 자기 쇼핑몰에서 상품을 팔고, 라이브 방송 중 들어온 주문을 OBS 화면에 대기열로 띄워 순서대로 오픈(개봉)한다.
대상: 트레이딩카드(TCG) 브레이크 등 라이브 커머스 판매자.
브랜드명·로고는 미정. 아래 [브랜드 제안]대로 후보를 추천하고, 화면에는 1순위 후보를 적용하되 쉽게 바꿀 수 있게 구성할 것.
모든 UI 문구는 한국어.

[사용자]
1. 플랫폼 마스터 관리자(대표·플랫폼 운영팀): 모든 판매자·구독·결제·운영 상태를 통합 관리
2. 판매자(운영자): PC에서 방송하며 판매자 관리자 화면 조작
3. 구매자: 주로 모바일에서 쇼핑몰 주문
4. 시청자: 방송 화면(OBS 오버레이)만 봄

[브랜드 제안]
- 브랜드명 후보 5개 추천: 한글명·영문명, 의미, 추천 이유, 어울리는 도메인 예시
  - 판매자 대상 B2B 구독 서비스이면서 라이브 방송·쇼핑몰·주문 대기열을 연상시킬 것
  - 짧고 부르기 쉬우며 TCG에 한정되지 않는 이름 (다른 라이브 커머스 업종으로 확장 가능)
  - 실제 존재하는 유명 브랜드·상표와 겹치거나 비슷한 이름은 피할 것
- 1순위 후보 기준 로고 시안 3종: 심볼+워드마크, 워드마크 단독, 앱·파비콘용 심볼
  - 방송 화면(OBS 오버레이) 위와 다크 관리자 화면에서도 잘 보일 것
  - 컬러·흑백·작은 크기(16px 파비콘) 버전 포함
- 브랜드 컬러 팔레트와 서체 제안, 다른 후보 선택 시 교체할 부분 명시
- 최종 확정은 대표님이 한다. 상표 등록 가능 여부는 확정 전 별도 확인 필요 (추천 시점에는 미확인으로 표시)

[디자인할 화면 — 우선순위 순]

1) OBS 오버레이 (방송 송출용, 배경 투명)
- 세로형 1080×1920, 가로 사이드형 500×900 두 가지
- 주문 대기열: 대기 / 오픈 중(카운트다운 타이머) / 완료 / 취소 상태 구분
- HIT 카드 강조 연출 (당첨 카드 등록 시 크게 노출되는 순간)
- 구매 랭킹(선택 표시)
- 개인정보 보호: 회원ID·실명 비노출, 닉네임만 표시
- 방송 화면 위에 얹히므로 가독성 높은 대비, 과하지 않은 애니메이션

2) 판매자 관리자 (데스크톱, 방송 중 한 손으로 빠르게 조작)
- 실시간 대기열 대시보드: 주문 순서, 상태 변경(오픈 시작 / 완료 / 취소), 타이머 설정, HIT 카드 등록
- 상품 관리: 상품 등록·이미지·가격·재고
- 주문 관리: 주문 목록·상세·결제 상태·취소/환불 상태
- 적립금 관리: 회원 등급별 적립률(카드/무통장 구분), 지급·회수 원장(대기/성공/실패), 회원별 잔액, 실지급 스위치(기본 꺼짐, 켤 때 경고 확인)
- 오버레이 설정: 표시 항목·색상·위치, 오버레이 URL 복사
- 설정: 쇼핑몰 정보, PG 연결 상태(판매자 명의 PG), 주문자 알림 설정, 구독 상태

3) 플랫폼 마스터 관리자 (데스크톱 1920×1080, 플랫폼 운영 전용 — 판매자 관리자와 분리된 별도 콘솔)
- 통합 대시보드: 전체 판매자 수·신규 가입·구독 매출(MRR)·결제 실패·오늘 방송 중인 판매자·주문 수·장애/오류 알림
- 판매자 관리: 판매자 목록·검색·상세(쇼핑몰·구독·PG 연결·방송 이력), 가입 승인/반려, 이용 정지·해제, 판매자 화면 대리 조회(읽기 전용, 접근 기록 남김)
- 구독·요금제 관리: 요금제 생성·수정(가격·제공량), 판매자별 구독 상태(체험/이용 중/연체/해지), 구독료 청구·결제 내역·환불 요청 처리
- 정산·결제 현황: 판매자별 PG 연결 상태·오류, 플랫폼 구독료 수납 현황
- 운영 현황: 판매자별 주문·방송·오버레이 접속 현황, 적립금 실지급 스위치가 켜진 판매자 목록
- 고객지원: 판매자 문의·답변, 공지사항 작성·발송
- 관리자 계정·권한: 마스터 관리자 계정 추가, 역할별 권한(최고관리자/운영/CS/조회 전용)
- 감사 로그: 누가 언제 무엇을 바꿨는지(판매자 정지, 요금제 변경, 대리 조회 등) 조회
- 시스템 설정: 플랫폼 기본 정책, 알림 채널 설정, 점검 모드

4) 구매자 쇼핑몰 (모바일 우선)
- 판매자별 쇼핑몰 홈, 상품 목록, 상품 상세, 장바구니, 주문서(방송 닉네임 입력란 포함), 주문 완료, 내 주문 조회, 내 적립금
- 판매자마다 로고·대표 색상을 바꿀 수 있는 테마 구조

5) 플랫폼 소개·가입
- 서비스 소개, 기능 안내, 요금 안내(월 99,000원 — 제안가, 제공량은 "추후 안내"로 표시), 판매자 가입·로그인

[디자인 요구사항]
- 하나의 디자인 시스템으로 통일: 색상·타이포·간격·버튼·입력·표·배지·모달·토스트 컴포넌트 정의
- 상태 배지 색상 일관성: 대기 / 오픈 중 / 완료 / 취소 / 실패
- 판매자 관리자·마스터 관리자는 라이트·다크 모드 모두 제공 (방송 환경은 다크 선호). 두 관리자 화면은 한눈에 구분되게 할 것
- 빈 상태·로딩·오류 상태 화면 포함
- 접근성: 충분한 명도 대비, 키보드 조작 가능

[산출물]
- 브랜드명 후보 5개와 1순위 로고 시안 3종, 브랜드 컬러·서체
- 화면별 디자인 (위 우선순위 1 → 5 순서)
- 공통 디자인 시스템 페이지
- 각 화면의 주요 상태(빈 상태, 주문 많음, 오류) 변형
- 개발 이관용 컴포넌트 목록

[제외]
- 실제 존재하는 다른 회사 브랜드 로고·상표 사용·모방 금지
- 실제 고객 데이터 금지, 예시 데이터는 가상의 닉네임·상품으로 작성
```
