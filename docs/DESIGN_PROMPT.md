## 클로드디자인 실행 설정 (프롬프트 붙여넣기 전에 지정)

| 항목 | 권장 | 이유 |
|---|---|---|
| 모델 | **Claude Fable 5.1** (목록에 없으면 **Claude Opus 5.5**) | Fable 5.1이 현재 가장 성능 높은 모델이다. 화면 수가 많고 길게 이어지는 작업이라 최상위 모델이 누락이 적다. |
| 노력(effort) | **최대(max)** (없으면 xhigh → high 순) | 노력 단계는 낮음(low) · 중간(medium) · 높음(high) · 매우 높음(xhigh) · 최대(max)다. 높을수록 더 깊게 검토하고 빠뜨림이 줄어든다. 대신 느리고 사용량이 많다. Opus 5.5는 기본값이 중간(medium)이라 반드시 직접 올린다. |

- 모델 정보 기준일: 2026-10-02 KST. 클로드디자인 화면에 표시되는 모델·노력 선택지 이름은 직접 확인하지 못했다. 화면에 있는 것 중 가장 높은 모델과 가장 높은 노력을 고른다.
- 사용량 한도에 걸리면 같은 대화에서 「남은 화면부터 이어서 진행」이라고 지시한다. 화면 목록 표가 있으므로 이어받을 수 있다.
