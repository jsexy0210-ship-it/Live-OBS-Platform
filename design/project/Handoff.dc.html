저장소 구조(app / components / lib, Next.js) 기준 제안 경로. 스타일 토큰은 Montage(WDS) 구조의 변수 이름을 쓰되 값은 A안(큐 바이올렛 · 웜 뉴트럴 · Wanted Sans)으로 lop.css에서 덮어써요. 오버레이는 ov.css. 모든 컴포넌트는 라이트/다크 모두 지원(data-theme).

토큰 · 테마 규칙

1. 색은 항상 WDS 시맨틱 변수(--wds-label-*, --wds-background-*, --wds-status-*)로 참조, 원색 hex 직접 사용 금지. 2. 브랜드 4변수 (--brand-name · --brand-ko · --brand · --brand-ink)와 A안 토큰 덮어쓰기는 lop.css 한 곳. 3. 쇼핑몰은 파트너스 설정값을 --shop / --shop-ink 로 주입. 4. 다크는 data-theme="dark" 루트 속성 하나로 전환(토큰 재매핑, 필터 금지). 5. 상태 배지 색 매핑은 StatusBadge 한 곳에서만 정의. 6. 포커스 링 2px/offset 2px 전역, 제거 금지.
