페이지 이동 · 마스터 · 판매자 · 구매자 공통

전체 건수와 offset 직접 이동을 제공하는 목록은 처음 · 이전 · 번호 · 다음 · 마지막을 표시합니다. PC는 번호 10개, 휴대폰은 5개씩 현재 번호가 포함된 그룹을 표시합니다. 번호 사이는 4, 그룹 사이는 PC 12 · 휴대폰 8이며 휴대폰은 탐색 버튼과 번호가 두 줄로 배치됩니다. 현재 번호는 기존 대표 색과 aria-current로 표시하고 첫·마지막 경계 버튼은 비활성입니다.

0건 목록은 페이지 이동을 숨깁니다. 잘못된 page는 실제 존재하는 1~총페이지 범위로 정규화합니다. 같은 목록에서 페이지를 바꿔도 적용한 검색·필터·정렬·개수는 유지합니다.

cursor · 방문한 쪽만 번호로 이동

cursor 목록은 확보한 커서의 방문 번호만 표시합니다. 다음 요청 전에는 4번을 만들지 않고 마지막 버튼도 만들지 않습니다. 첫 쪽과 이전 쪽은 저장된 커서로만 이동합니다. 전체 건수가 있어도 임의 번호·마지막 이동에 필요한 API 계약이 없으면 만들지 않습니다.
