브랜드 제안

브랜드명 후보 5안

기준: 파트너스 대상 B2B 구독 서비스 · 라이브 방송 + 쇼핑몰 + 주문대기 연상 · 짧고 부르기 쉬움 · TCG에 한정되지 않음 · 유명 상표와 겹치지 않을 것.

상표 등록 가능 여부: 전 후보 미확인 — 확정 전 별도 조사 필요
1순위 · 화면 적용상표 미확인
ONQ온큐

의미 — ON(방송 중, 켜짐) + Q(Queue 주문대기, 그리고 "큐 사인"). "지금 온에어, 다음 주문은 큐에".

추천 이유 — 3글자로 가장 짧고, 한글 "온큐"가 발음·표기 모두 안정적. 방송과 주문대기 두 축을 동시에 담으며 업종 중립적. 심볼(링 + 온에어 점)로 바로 확장.

도메인 예시 — onq.live · onq.kr · getonq.com

짧음업종 중립심볼화 쉬움
2순위상표 미확인
OpenQ오픈큐

의미 — Open(개봉·오픈) + Queue. "오픈할 순서가 줄 서 있다".

추천 이유 — 핵심 동작인 "오픈"을 이름에 직접 노출해 파트너스에게 기능이 즉시 설명됨. 브레이크·언박싱·경매형 라이브 전반으로 확장 가능.

도메인 예시 — openq.kr · openq.live · openq.shop

기능 직관유사 명칭 많을 수 있음
3순위상표 미확인
Qcast큐캐스트

의미 — Queue + Broadcast. "주문대기를 방송한다".

추천 이유 — OBS 오버레이(송출)라는 제품 특성을 가장 직접적으로 드러냄. 영문 발음이 또렷하고 해외 확장 시에도 의미가 통함.

도메인 예시 — qcast.kr · qcast.live · qcast.app

송출 연상"cast" 계열 서비스와 혼동 가능
4순위상표 미확인
Livesell라이브셀

의미 — Live + Sell. "라이브로 판다".

추천 이유 — 라이브 커머스 전반을 포괄하는 가장 넓은 이름. 쇼핑몰 쪽 정체성이 강해 구매자 접점(쇼핑몰 푸터 "Powered by")에서도 어색하지 않음.

도메인 예시 — livesell.kr · livesell.shop

확장성 최대일반어 조합 — 식별력 약함
5순위상표 미확인
Soonseo순서

의미 — 한국어 "순서"를 그대로. "순서대로 개봉해요".

추천 이유 — 국내 파트너스·시청자에게 가장 친근하고 기억에 남음. 방송 중 "순서 띄울게요"처럼 자연어로 쓰임. 영문 표기는 로마자 그대로.

도메인 예시 — soonseo.kr · soonseo.live

친근 · 기억성해외 확장 시 의미 전달 어려움
화면 전체에는 1순위 ONQ를 적용했어요. 다른 후보로 바꾸려면 공통 스타일(lop.css)의 --brand-name / --brand-ko 두 값과 로고 심볼만 교체하면 돼요. 최종 확정은 대표님이 하며, 확정 전 상표·도메인 조사가 필요해요.
